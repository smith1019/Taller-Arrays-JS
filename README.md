# Taller 5-3: Arrays en JavaScript

Taller de JavaScript para practicar la manipulación de datos con métodos de arrays.

## Datasets

Reservas de hotel, inventario de supermercado, estudiantes, recursos humanos, videojuegos y banco.

## Métodos practicados

- `sort`: ordenar
- `filter`: filtrar
- `map`: transformar cada elemento
- `reduce`: sumar, encontrar el mayor y agrupar

## Ejecutar

Abre el archivo `.html` en el navegador y revisa los resultados en la consola
